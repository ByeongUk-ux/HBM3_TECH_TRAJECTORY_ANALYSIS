# HBM3 8-Hi → 12-Hi 공정기술 공진화 연구

SK하이닉스 HBM3의 DRAM 적층 수가 8개에서 12개로 증가하는 과정에서, 제품특성과 후공정 기술이 어떻게 함께 발전했는지 분석하기 위한 연구 저장소입니다.

현재는 **1단계: 문헌 기반 후공정 기술 후보 도출**까지 진행했습니다. 기술 중요도 평가, 교차영향분석(Cross-impact Analysis), 공진화 경로 도출은 아직 수행하지 않았습니다.

## 연구범위

| 항목 | 범위 |
|---|---|
| 분석기업 | SK하이닉스 |
| 제품 세대 | HBM3 |
| 비교 대상 | 8-Hi 16GB → 12-Hi 24GB |
| 중심 영역 | 박막화, 다이 분리, TSV·범프 접속, 적층·접합, 언더필·몰딩, 계측·검사·시험 |
| 비교 기준 | 2022년 초기 양산 8단과 2023년 샘플 공개·공급 단계의 12단 |
| 자료 기준일 | 2026-10-18 |

HBM3E·HBM4의 제품 차이를 HBM3 8단→12단의 변화로 사용하지 않습니다. TSV 형성처럼 전·후공정 경계에 있는 기술과 설계·시험 지원 기술은 후보 목록에서 별도로 표시했습니다.

방법론의 참고 논문은 이병준·신준석(2020), 「공진화 분석기반 기술 인텔리전스: 반도체 패키지공정 사례」입니다. [DOI: 10.14386/SIME.2020.28.4.63](https://doi.org/10.14386/SIME.2020.28.4.63)

**원논문 확인 상태:** 서지와 초록은 확인했지만, `Target_Paper.pdf` 본문 접근에 실패해 Ⅲ장·Ⅳ장 1절을 직접 확인하지 못했습니다. 현재 후보 도출 절차는 연구자가 제공한 작업 지침을 기준으로 구성했습니다.

## 현재 산출물

| 항목 | 수량 |
|---|---:|
| 기술 후보 | 35개 |
| 문헌 기록 | 29개 |
| 기술적 문제 | 11개 |
| 문제–기술 대응 관계 | 44개 |
| 검색식 | 32개 |
| 자료 접근 기록 | 30개 |

문헌 29개에는 참고 방법론 논문과 본문 미확보 자료도 포함됩니다. 모두 제품 적용을 검증한 문헌이라는 뜻은 아닙니다.

### 변화 유형과 근거 수준

| 변화 유형 | 개수 |
|---|---:|
| 공통 | 3 |
| 개선 | 2 |
| 신규 적용 | 1 |
| 미확인 | 29 |

| 근거 수준 | 개수 | 의미 |
|---|---:|---|
| A | 10 | 해당 제품 적용 또는 개발 중 사용을 일차 자료에서 직접 확인 |
| B | 12 | 학술문헌·특허·학술 기술로드맵에서 관련 기술을 확인했으나 특정 제품 채택은 미확인 |
| C | 13 | 제품과의 연결이 가설적이거나 직접 자료가 부족함 |

두 분류는 서로 다릅니다. **근거 A 10개 중 4개는 12단 적용·개발 활동이 확인되지만 8단과의 변화 유형은 미확인**입니다. 따라서 미확인 29개는 `제품 직접 근거가 있는 4개 + 실제 제품 적용을 추가 확인할 25개`로 나뉩니다.

‘신규 적용’은 공식 자료가 12단 개발에서 도입했다고 설명하는 구현을 뜻합니다. 기술 자체의 최초 발명 시점이나 모든 8단 제품에서의 미사용을 증명한 것은 아닙니다.

### 읽는 순서

1. 보고서의 연구범위·검증 기준·제품 비교를 읽습니다.
2. 후보 CSV에서 관심 기술의 `Technology ID`를 확인합니다.
3. `Source ID`를 문헌 DB와 연결해 원문 위치 및 확인 상태를 확인합니다.
4. 대응표에서 기술적 문제와의 연결이 제품에서 확인된 것인지 가설인지 확인합니다.
5. `Verification Needed`를 기준으로 후속 문헌 조사와 전문가 질문을 준비합니다.

`T01`–`T35`는 기술 ID, `S00`–`S28`은 문헌 ID입니다. 여러 Source ID는 세미콜론으로 구분합니다. CSV는 쉼표 구분, UTF-8 BOM 형식이며 Excel에서는 UTF-8로 가져올 수 있습니다. ‘미확인’을 미사용 또는 0으로 치환하지 않습니다.

## 해석상 주의점

- **35개는 전문가 검증 전 후보 목록입니다.** 구조 기술, 제조 구현, 재료, 개발 활동, 검증 방법의 수준이 일부 혼재합니다.
- MR-MUF 계열과 MR 접합·MUF 봉지, EMC 재료·충전 조건은 상하위 관계가 있으므로 중복 평가 여부를 검토해야 합니다.
- 공통·개선·신규로 분류한 6개만으로 최종 분석대상을 확정하지 않았습니다. 직접 근거가 있는 10개부터 정의와 중복 관계를 검토하고 공정의 빈 부분을 확인합니다.
- 특허의 존재·우선일·출원인이 실제 제품 채택을 증명하지 않습니다.
- 기업이 밝힌 문제–대응 관계와 독립 실험으로 검증된 인과효과를 구분합니다.
- 2021년 24GB 개발 발표와 2023년 12단 제품의 공정 revision 관계가 완전히 확인되지 않았습니다. 서로 다른 자료의 절대 두께·개선율을 조합하지 않습니다.
- 일부 자료는 공식 검색 색인의 초록·부분 텍스트만 확인했습니다. 문헌 DB의 `Verification Status`를 확인해야 합니다.

## 네 기준에 따른 1차 선별 (2026-10-18)

기존 35개 후보에 연구범위 적합성, 기술적 독립성, 적층 고도화 관련성, 검증 가능성을 적용했습니다.

- **18개 잠정 평가단위:** 단독 유지 12개와 통합 제안 6개. 제조 12개, 계측·검사·시험 6개로 구성합니다.
- **원래 35개 행의 처리:** 선정 대표 18개 + 통합 흡수 6개 + 보류 6개 + 보조자료 분리 3개 + 독립 후보 제외 2개입니다.
- 기술의 존재·역할에 관한 문헌 근거와 SK하이닉스 제품 채택 근거를 구분합니다. 제품 적용 미확인만으로 자동 제외하지 않았습니다.
- 독립성은 상하위 개념·동일 기능을 중복 평가하지 않는다는 뜻입니다. 기술 간 영향이 없어야 한다는 뜻은 아닙니다.
- 6개 통합안은 연구자의 기능 단위 정규화 제안입니다. 서로 다른 대안 공법이나 재료 물성이 실제로 동일한 기술임을 입증한 결과는 아닙니다.

## 다음 연구 단계

1. Follow Paper 본문을 확보해 후보 도출 단위를 대조합니다.
2. 제품별 적용·기술 정의·공정 경계와 중복 관계를 전문가에게 검증합니다.
3. 제품특성을 도출하고 공정기술의 평가 단위를 정제합니다.
4. 제품특성–공정기술 간 교차영향분석을 설계합니다.
5. 검증된 분석 결과를 바탕으로 공진화 경로를 해석합니다.

후보 통합·분할 및 근거 갱신 시 기존 Technology ID·Source ID와의 관계를 기록해 변경 이력을 유지합니다.
