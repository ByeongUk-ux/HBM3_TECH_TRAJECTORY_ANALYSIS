# HBM3 8-Hi → 12-Hi 공정기술 1차 선별

작성일: 2026-10-18  
대상: 기존 T01–T35 기술 후보  
성격: 네 가지 적합성 기준에 따른 연구자의 1차 선정·통합 제안

## 1. 결과

**기존 35개 항목 중 24개 항목을 18개 잠정 평가단위로 정리했다.** 이 중 12개는 단독 유지, 6개는 통합 제안이다. 나머지 11개는 보류 6개, 보조자료 분리 3개, 독립 후보 제외 2개로 처리했다.

| 원래 35개 행의 처리 | 행 수 | 의미 |
|---|---:|---|
| 선정 대표 | 18 | 각 새 평가단위를 대표하는 원래 ID |
| 통합 흡수 | 6 | 대표 항목과 함께 하나의 평가단위로 묶는 원래 ID |
| 보류 | 6 | 범위·구현·중복 문제를 해결한 뒤 재검토 |
| 보조자료 분리 | 3 | 개발·해석·시험체 지원 자료로 유지 |
| 독립 후보 제외 | 2 | 상위 기술 계열 또는 이번 평가범위 밖의 선행 형성 기술로 이동 |
| 합계 | 35 | 원래 후보 누락 없음 |

18개 평가단위는 **제조 기술 12개와 계측·검사·시험 기술 6개**다. 원래 조사범위에 Testing/Reliability가 포함되어 있어 검사·신뢰성 시험을 일괄 제외하지 않았다.

이 수치는 기술 중요도나 최종 공진화 분석 변수 수가 아니다. 제품 적용을 모두 확인한 18개라는 뜻도 아니다. 전문가가 특히 6개 통합안의 평가 수준을 검토해야 한다.

## 2. 선정 기준의 적용

| 사용자가 제시한 기준 | 적용한 판단 |
|---|---|
| 연구범위 적합성 | HBM 내부 다이 적층의 제조, 후면 MEOL, 계측·검사·신뢰성 시험에 해당하는가? |
| 기술적 독립성 | 수행 기능·대상·단계를 구분할 수 있고, 상하위 항목을 중복 평가하지 않는가? |
| 적층 고도화 관련성 | 박막화·협소 간극·휨·접합·수율·신뢰성 등의 요구와 연결되는가? |
| 검증 가능성 | 기술의 존재와 역할을 뒷받침하는 원문 기술자료·논문·특허가 있는가? |

각 기준은 `충족 / 조건부 / 미충족`으로 판단했다. 총점·가중치·중요도 순위를 부여하지 않았다. 적층 관련성은 `제품 직접 설명`과 `일반 공정 원리에서의 연결`을 따로 기록했다.

### 2.1 기술 존재 확인과 제품 적용 확인은 다르다

이번 검증 가능성 기준은 **기술의 존재·역할에 대한 문헌 근거**다. SK하이닉스 8단·12단 채택의 직접 확인을 필수 통과 조건으로 바꾸지 않았다. 따라서 기존 근거 B/C 항목도 존재·역할이 일차 기술문서로 확인되면 1차 후보로 유지할 수 있다.

반대로 기존 근거 A여도 구체 구현이나 독립 평가 가능성이 불명확하면 보류했다. T19·T20·T35가 이에 해당한다. 기존 A/B/C 등급은 원자료 그대로 보존하며 이번 선별 등급으로 덮어쓰지 않는다.

### 2.2 독립성의 의미

여기서 독립성은 “서로 영향을 주지 않는다”는 뜻이 아니다. 교차영향분석에서는 기술 간 영향이 존재할 수 있다. **같은 공정 능력이나 상하위 개념을 여러 행에서 반복 평가하지 않도록 경계를 정한다**는 뜻이다.

평가 수준은 우선 `공정 기능 단위`로 맞췄다. 대안 구현이나 같은 재료의 물성은 묶는 방안을 제시했지만, 이를 기술적으로 동일한 공법이라고 단정하지 않는다. 기능별로 묶는 선택 자체가 연구자의 정규화 제안이다.

### 2.3 범위 판단에서 사용한 해석

- 임시 지지, 후면 노출·절연·평탄화 등 MEOL은 후공정 연계 영역으로 포함한다. S12는 이들 기능의 존재를 설명하지만 SK하이닉스 공정표는 아니다.
- SEM 불량분석, FEA, proxy 시험체 설계는 관련성이 없는 기술로 삭제하지 않는다. 제조·검사·시험을 지원하는 보조층에 보존한다.
- TSV 식각·절연·충전 자체는 선행 공정과의 경계를 확정하지 못했으므로 이번 직접 평가목록에서 분리한다. 실제 공정 소관을 확인하면 재편입 가능하다.
- 시험기술의 제품특성 영향은 “불량 선별·출하품질/수율” 등으로 정의해야 한다. 시험이 칩의 물리적 성능을 직접 높인다고 가정하지 않는다.

### 3.2 실제 8단→12단에서 중요성이 높아졌다는 주장은 하지 않는다

적층 관련성은 선정 적합성이다. 중요도 증가의 증거가 아니다. 예를 들어 박막 다이 분리·정렬·KGD가 관련 기술이라는 판단은 가능하지만, 특정 공법이 12단에서 신규 채택되었거나 8단보다 중요해졌다는 판단은 별도의 제품·전문가 근거가 필요하다.

## 4. 통합 제안 6개와 주의점

위 통합은 문헌에서 “동일 기술”임을 증명한 결과가 아니다. 연구자의 평가 단위 통일안이다. 네 기준 중 독립성이 조건부였던 항목을 어떻게 처리했는지 추적 가능하게 남긴 것이다.

특히 **T35의 제품 직접 근거가 있다는 사실과 독립 기술 구현이 확인됐다는 사실은 다르다.** 정체가 불명확한 “휨 제어”를 PT02 또는 PT10에 임의로 합치지 않았다.

T11은 중요하지 않아서 제외한 것이 아니다. TSV–범프 수직접속이라는 상위 구조·기술 계열을 하위 공정들과 동시에 한 행으로 평가하면 수준이 섞이므로 배경 기술로 이동했다.

## 7. 다음에 검증할 사항

1. **6개 통합안의 수준:** 대안 공법·재료 물성·검사법을 기능 단위로 묶는 것이 연구 질문에 맞는지 전문가 검토.
2. **13개 일반 후보의 제품 연결:** 장비 채택 여부를 모두 알아야 한다는 뜻은 아니지만 실제 HBM3 적용 또는 타당한 적용 범위 확인이 필요.
3. **6개 보류 항목의 정체:** 범용 활동명·변화된 형상·기능 언급을 구체적인 공정 구현으로 특정.
4. **제조와 시험의 영향 정의:** 계측·검사·신뢰성 시험을 포함할 경우 제품특성에 품질/신뢰성·수율 등을 어떻게 반영할지 정리.
5. **원논문 정합성:** Follow Paper 지정 본문은 아직 확인하지 못했다. 분석 수준과 전문가 검증 절차를 원문과 대조해야 함.

현재 18개는 전문가에게 제시할 1차안이다. 이를 그대로 확정 교차영향행렬로 투입하거나 기술 중요도·공진화 경로가 검증된 목록으로 표현하지 않는다.
